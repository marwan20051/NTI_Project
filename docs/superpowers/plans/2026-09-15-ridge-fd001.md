- [ ] **Step 2: Implement scaled model creation and validation-only tuning**

Create models only through:

```python
def _ridge_pipeline(alpha: float) -> Pipeline:

        ("scaler", StandardScaler()),
        ("ridge", Ridge(alpha=alpha)),
    ])
```

Use `prepare_experiment_data`, `baseline_data`,
`engineered_validation_data`, and `engineered_final_data`. Fit the raw baseline
with alpha 1 and its uncapped training target. For each candidate alpha, fit an

Do not read official labels during alpha selection.
